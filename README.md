# NMT Daily

> **Відкрий застосунок:** [https://kolomiecana875-cyber.github.io/NMTv3/](https://kolomiecana875-cyber.github.io/NMTv3/)

NMT Daily — застосунок для підготовки до НМТ із щоденним повторенням і тематичними тренуваннями.

## Головні функції

- Щоденні добірки запитань і перегляд результатів.
- Тренування з обраного предмета та налаштування кількості завдань.
- Статистика навчання, серії занять і зірки за прогрес.
- Ігрове місто, яке розвивається завдяки виконаним завданням.
- Профіль із прогресом і історією повторень.

## Локальний запуск

Потрібен Node.js і npm.

```bash
npm install
npm run dev
```

Для production-збірки виконай:

```bash
npm run build
```
